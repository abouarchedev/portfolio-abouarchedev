## À propos du projet

Ce projet est mon portfolio personnel, conçu pour présenter mon profil professionnel dans le domaine du développement Web Full Stack.

Il permet aux recruteurs, entreprises, développeurs et visiteurs de découvrir mon parcours, mes compétences techniques, mes réalisations, ma formation et mes certifications.

L'objectif est de disposer d'un espace professionnel en ligne qui reflète mon identité de développeur, valorise mon travail et facilite la prise de contact pour des opportunités professionnelles, notamment un stage d'application.

Le portfolio a été développé avec React et Vite, avec une interface moderne, responsive et bilingue.

## Fonctionnalités

- **Design moderne et minimaliste :** interface soignée avec une identité visuelle basée sur le blanc, le bleu et les nuances de gris.
- **Responsive Design :** adaptation aux écrans d'ordinateurs, tablettes et smartphones.
- **Mode clair et sombre :** possibilité de changer le thème d'affichage.
- **Interface bilingue :** contenu disponible en français et en anglais.
- **Navigation fluide :** accès aux différentes sections depuis la barre de navigation.
- **Animations et interactions :** transitions et effets visuels pour améliorer l'expérience utilisateur.
- **Présentation des projets :** cartes dédiées aux réalisations avec accès aux dépôts GitHub.
- **Certifications :** présentation des certificats avec aperçus et liens de vérification lorsqu'ils sont disponibles.
- **CV :** accès au téléchargement du CV.
- **Contact :** section dédiée aux prises de contact professionnelles.

## Installation et lancement

Pour exécuter le projet localement, Node.js et npm doivent être installés.

### 1. Cloner le dépôt

```bash
git clone https://github.com/abouarchedev/portfolio-abouarchedev.git
```

### 2. Accéder au dossier

```bash
cd portfolio-abouarchedev
```

### 3. Installer les dépendances

```bash
npm install
```

### 4. Lancer le serveur de développement

```bash
npm run dev
```

Le projet sera accessible à l'adresse locale indiquée dans le terminal, généralement :

```text
http://localhost:5173
```

## Scripts disponibles

| Commande | Description |
|---|---|

| `npm run build` | Génère la version optimisée pour la production. |

## Build et déploiement

Le projet utilise Vite pour générer les fichiers optimisés destinés à la production.

Pour créer le build :

```bash
npm run build
```

Les fichiers générés sont placés dans le dossier `dist/`.
